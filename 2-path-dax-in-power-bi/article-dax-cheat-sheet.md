# DAX Cheat Sheet: Reference Guide

This reference guide provides a structured overview of the most essential Data Analysis Expressions (DAX) functions, statements, and operators used in Power BI.

---

## 1. Mathematical & Statistical Functions
These functions handle everything from basic arithmetic operations to complex analytical aggregations.

| Function | Description | Example |
| :--- | :--- | :--- |
| SUM() | Adds all numbers in a column. | SUM('Vendas'[TotalVendas]) |
| SUMX() | Sums an expression evaluated for each row of a table. | SUMX('Produtos', 'Produtos'[Preço] * 'Produtos'[Quantidade]) |
| AVERAGE() | Returns the arithmetic mean of a column. | AVERAGE('Notas'[Pontuação]) |
| AVERAGEX() | Calculates the average of an expression evaluated over a table. | AVERAGEX('Vendas', 'Vendas'[Valor] * 'Vendas'[Quantidade]) |
| MEDIAN() | Returns the median of a column. | MEDIAN('Idades'[Idade]) |
| MEDIANX() | Calculates the median of an expression evaluated over a table. | MEDIANX('Clientes', 'ReceitaAnual') |
| GEOMEAN() | Calculates the geometric mean of a column. | GEOMEAN('Investimentos'[Retorno]) |
| GEOMEANX() | Calculates the geometric mean of an expression over a table. | GEOMEANX('Ações', 'Ações'[RetornoDiário]) |
| COUNT() | Counts cells in a column containing non-blank values. | COUNT('Vendas'[ClienteID]) |
| COUNTX() | Counts non-blank rows of an expression evaluated over a table. | COUNTX('Vendas', IF('Vendas'[Valor] > 0, 1, 0)) |
| DIVIDE() | Safe division handling division-by-zero errors automatically. | DIVIDE([Vendas], [Custo], 0) |
| MIN() | Returns the minimum value of a column. | MIN('Vendas'[TotalVendas]) |
| MAX() | Returns the maximum value of a column. | MAX('Vendas'[TotalVendas]) |
| COUNTROWS() | Counts the total number of rows in a table. | COUNTROWS('Vendas') |
| DISTINCTCOUNT()| Counts the number of unique distinct values in a column. | DISTINCTCOUNT('Vendas'[ClienteID]) |
| RANKX() | Returns the ranking of a number inside a list for each row. | RANKX('Vendas', 'Vendas'[Valor], , DESC, Dense) |

## 2. Filter Functions
Used to isolate specific data subsets, alter evaluation contexts, and manipulate active report filters.

| Function | Description | Example |
| :--- | :--- | :--- |
| FILTER() | Returns a filtered subset of a table or expression. | FILTER('Produtos', 'Produtos'[Vendas] > 1000) |
| CALCULATE() | Evaluates an expression modified by specific filters. | CALCULATE(SUM('Vendas'[TotalVendas]), 'Vendas'[Ano] = 2024) |
| HASONEVALUE() | Returns TRUE if the column has been filtered down to exactly one distinct value. | HASONEVALUE('Clientes'[Nome]) |
| ALLNOBLANKROW()| Returns all rows of a table ignoring filters, excluding blank rows generated by invalid relationships. | ALLNOBLANKROW('Produtos') |
| ALL() | Returns all rows/values ignoring any active report filters. | ALL('Produtos'[Nome]) |
| ALLEXCEPT() | Returns all rows except those affected by specified column filters. | ALLEXCEPT('Vendas', 'Clientes') |
| REMOVEFILTERS()| Completely clears filters from designated tables or columns. | REMOVEFILTERS('Vendas') |

---

## 3. Logical Functions
These functions analyze expressions to return conditional values or control query execution flows.

| Function | Description | Example |
| :--- | :--- | :--- |
| IF() | Checks a condition and returns value_a if true, or value_b if false. | IF('Vendas'[Valor] > 1000, "Alto", "Baixo") |
| AND() | Returns TRUE if both arguments are true. | AND('Clientes'[VIP], 'Vendas'[Ano] = 2024) |
| OR() | Returns TRUE if at least one argument is true. | OR('Clientes'[VIP], 'Vendas'[Ano] = 2024) |
| NOT() | Reverses a logical argument (TRUE becomes FALSE and vice-versa). | NOT('Produtos'[EmFalta]) |
| SWITCH() | Evaluates an expression against a list of values and returns a matching result. | SWITCH('Vendedores'[Vendas], 1, "Baixo", 2, "Médio", 3, "Alto", "Desconhecido") |
| IFERROR() | Evaluates an expression and returns an alternate value if an error occurs. | IFERROR([Lucro] / [Receita], 0) |

## 4. Date & Time Functions
Essential for creating calculations based on standard calendar fields and processing timeline information.

| Function | Description | Example |
| :--- | :--- | :--- |
| CALENDAR() | Returns a single-column table containing a contiguous set of dates. | CALENDAR(DATE(2024, 01, 01), DATE(2024, 12, 31)) |
| CALENDARAUTO()| Automatically generates a calendar table based on dataset limits. | See example below |
| DATE() | Returns the specified date in datetime format. | DATE(2024, 12, 25) |
| DATEDIFF() | Returns the number of intervals (days, months, years) between two dates. | DATEDIFF(DATE(2024, 12, 31), DATE(2024, 01, 01), DAY) |
| DATEVALUE() | Converts a text-formatted date into a standard datetime value. | DATEVALUE("2024-12-25") |
| DAY() | Returns an integer from 1 to 31 representing the day of the month. | DAY(DATE(2024, 12, 25)) |
| WEEKNUM() | Returns the calendar week number of the year for a given date. | WEEKNUM(DATE(2024, 12, 25)) |
| MONTH() | Returns an integer from 1 to 12 representing the month of the year. | MONTH(DATE(2024, 12, 25)) |
| QUARTER() | Returns an integer from 1 to 4 representing the calendar quarter. | QUARTER(DATE(2024, 12, 25)) |
 
 ```dax
Advanced CALENDARAUTO table generation expression:
ADDCOLUMNS (
    CALENDARAUTO (), 
    "Ano", YEAR ( [Date] ), 
    "Trimestre", "T" & QUARTER ( [Date] ), 
    "Mês", FORMAT ( [Date], "mmmm" ), 
    "Num Mês", MONTH ( [Date] ) 
)
```

## 5. Time Intelligence Functions
Enables the comparison of performance across historical periods (e.g., Year-Over-Year, Month-to-Date accumulations).

| Function | Description | Example |
| :--- | :--- | :--- |
| DATEMTD() | Returns a table of dates for the Month-To-Date period. | CALCULATE(SUM('Vendas'[TotalVendas]), DATESMTD('Calendário'[Data])) |
| DATEQTD() | Returns a table of dates for the Quarter-To-Date period. | CALCULATE(SUM('Vendas'[TotalVendas]), DATESQTD('Calendário'[Data])) |
| DATEYTD() | Returns a table of dates for the Year-To-Date period. | CALCULATE(SUM('Vendas'[TotalVendas]), DATESYTD('Calendário'[Data])) |
| DATEADD() | Shifts a date column by a specific interval (days, months, years). | DATEADD(DATE(2024, 01, 01), 7, DAY) |
| DATESBETWEEN()| Returns a table containing dates between a start and end boundary. | DATESBETWEEN('Calendário'[Data], DATE(2024, 01, 01), DATE(2024, 12, 31)) |
| TOTALYTD() | Evaluates the year-to-date value of an expression directly. | TOTALYTD(SUM('Vendas'[TotalVendas]), 'Calendário'[Data]) |
| SAMEPERIODLASTYEAR()| Shifts report dates exactly one year back to analyze historical changes. | SAMEPERIODLASTYEAR('Calendário'[Data]) |
| STARTOFMONTH() | Returns the first day of the month for a given date context. | STARTOFMONTH(DATE(2024, 12, 25)) |
| STARTOFQUARTER()| Returns the first day of the quarter for a given date context. | STARTOFQUARTER(DATE(2024, 12, 25)) |
| STARTOFYEAR() | Returns the first day of the year for a given date context. | STARTOFYEAR(DATE(2024, 12, 25)) |

## 6. Relationship Functions
Manage data model visibility and establish linkages across distinct tables.

| Function | Description | Example |
| :--- | :--- | :--- |
| CROSSFILTER() | Controls the cross-filtering direction used during a calculation. | CROSSFILTER('Pedidos'[ClienteID], 'Clientes'[ClienteID], BOTH) |
| RELATED() | Fetches a single related value from an upstream dimension table. | RELATED('Clientes'[Nome]) |
| RELATEDTABLE() | Evaluates a table expression inside an active relationship context. | COUNTROWS(RELATEDTABLE('Vendas')) |
| USERELATIONSHIP()| Temporarily activates an inactive table relationship during a calculation. | CALCULATE([Total Vendas], USERELATIONSHIP('Calendário'[Data], 'Vendas'[Data de Venda])) |

## 7. Table Manipulation Functions
These expressions shape, reshape, combine, or generate virtual tables for advanced logic.

| Function | Description | Example |
| :--- | :--- | :--- |
| SUMMARIZE() | Groups a table by specified attributes and returns calculated summary metrics. | SUMMARIZE('Vendas', 'Clientes'[Nome], "Total Vendas", SUM('Vendas'[Valor])) |
| DISTINCT() | Extracts a single-column table of unique entries, removing duplicates. | DISTINCT('Vendas'[ClienteID]) |
| ADDCOLUMNS() | Dynamically appends virtual calculated columns onto a base table. | ADDCOLUMNS('Vendas', "Lucro", 'Vendas'[Receita] - 'Vendas'[Custo]) |
| SELECTCOLUMNS()| Isolates specific columns from a target table, optionally renaming them. | SELECTCOLUMNS('Clientes', "Nome", 'Clientes'[Nome], "Idade", 'Clientes'[Idade]) |
| GROUPBY() | Creates a grouped summary of an input table via local iteration. | GROUPBY('Vendas', 'Ano', "Total Vendas", SUM('Vendas'[Valor])) |
| INTERSECT() | Returns a table containing rows present in both input datasets. | INTERSECT('Vendas', 'Orçamento') |
| NATURALINNERJOIN()| Combines two tables using an inner join based on matching column names. | NATURALINNERJOIN('Vendas', 'Clientes') |
| NATURALLEFTOUTERJOIN()| Combines two tables using a left outer join structure. | NATURALLEFTOUTERJOIN('Vendas', 'Clientes') |
| UNION() | Appends multiple tables vertically, row-by-row. | UNION('Vendas_Janeiro', 'Vendas_Fevereiro') |
| VALUES() | Returns unique entries from a column plus an optional empty relational row. | VALUES('Vendas'[Ano]) |

## 10. DAX Statements & Operators

### Statements
Special declarations used within expressions to organize assignments or alter row scopes.

* VAR / RETURN: Temporarily holds calculation values local to a measure or column.
  VAR TotalVendas = SUM('Vendas'[Valor])
  RETURN TotalVendas

* COLUMN: Syntax declaration explicitly storing an expression as a table physical row model component.
  COLUMN('Vendas'[Lucro] = 'Vendas'[Receita] - 'Vendas'[Custo])

* ORDER BY: Used in execution queries to define structural column sorting priorities.
  ORDER BY('Vendas'[Data] ASC)

### Operators
Logical, mathematical, and comparative symbols used to tie components together.

| Operator | Signification | Example |
| :---: | :--- | :--- |
| = | Equal to | Valor = 10 |
| == | Strict equality | Número == 5 |
| > | Greater than | Preço > 100 |
| < | Less than | Quantidade < 50 |
| >= | Greater than or equal to | Idade >= 18 |
| <= | Less than or equal to | Nota <= 7 |
| <> | Not equal to / Different | Estado <> "Finalizado" |
| & | String concatenation | Nome & Sobrenome |
| && | Logical AND | (Valor > 10) && (Quantidade < 100) |
| IN {} | Set membership check | Categoria IN {"Eletrônicos", "Móveis"} |
